# 📝 NoteCraft - Modern Note Taking Application

A beautiful, responsive note-taking application built with React, Redux, and Tailwind CSS. Create, edit, view, and manage your notes with a modern, intuitive interface.

## ✨ Features

- **📝 Create & Edit Notes** - Write and edit notes with a rich text editor
- **🔍 Search Functionality** - Find your notes quickly with real-time search
- **👁️ View Notes** - Read your notes in a clean, distraction-free interface
- **📤 Share Notes** - Share your notes with others via generated links
- **📋 Copy to Clipboard** - Easy copying of note content
- **🗑️ Delete Notes** - Remove unwanted notes with confirmation
- **💾 Local Storage** - All notes are saved locally in your browser
- **📱 Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **⚡ Fast Performance** - Optimized for speed and efficiency

## 🛠️ Built With

- **React** - Frontend framework
- **Redux Toolkit** - State management
- **React Router** - Navigation and routing
- **Tailwind CSS** - Styling and responsive design
- **Lucide React** - Beautiful icons
- **React Hot Toast** - Notifications and alerts
- **Vite** - Build tool and development server
